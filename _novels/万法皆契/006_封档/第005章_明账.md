# 第5章 明账

勘契司·档房。沈篆把明账，整理了一遍。

他又想了一遍"明账"。明账——是摆明面的账——他想着这个，又想着明的账——明，是不怕看——他想着这个，把这个念头放好：明账的账，他做。

他又想了一遍"明账的账，他做"。做——是把账摆明——他想着这个，又想着做的账——摆明，是引暗手——他想着这个，把这个念头放好：引的账，他做。

他坐在案边，面前摊着他核过的实账。实账——是他核实的——他想着这个，又想着实的账——实账，摆得出来——他想着这个，把这个念头放好：实账，他摆。

他又想了一遍"他核实的"。他核实的——是他亲眼核的——他想着这个，又想着亲的账——亲核，是作数——他想着这个，把这个念头放好：亲核的账，他摆。

他又想了一遍"亲核的账，他摆"。亲核——是他亲眼核的——他想着这个，又想着亲的账——亲核，作数——他想着这个，把这个念头放好：作数的账，他摆。

他推演。

第一步，立结论：黑名单反击，第一手是明账——把实账整理好，摆到明处——被看着的账，最实。

第二步，摆依据，三样。一，实——他核的账，是实的——摆得出来；二，黑——严鉴看着他，他摆实的——看着的账，改不得；三，明——实账摆明处，暗手就露——明账对暗手。三样并排：实账，看着，摆明——明账，他做。

第三步，定行动。明账，他整理——整理好，摆明面——摆出去，引暗手。

他数了三息，把三步在心里过完。

他又想了一遍"明账对暗手"。明账——是明的——暗手——是暗的——他想着这个，又想着对的账——明的摆出来，暗的就藏不住——他想着这个，把这个念头放好：对暗的账，他做。

他又想了一遍"暗的藏不住"。藏不住——是露了——他想着这个，又想着露的账——露了，是能抓——他想着这个，把这个念头放好：能抓的账，他记。

他又想了一遍"能抓的账，他记"。能抓——是暗手露了能抓——他想着这个，又想着抓的账——抓到手，账就实——他想着这个，把这个念头放好：抓实的账，他记。

他又想了一遍"引暗手"。引——是引暗手来——他想着这个，又想着引的账——引到明账上，暗手就露——他想着这个，把这个念头放好：引的账，他做。

他又想了一遍"引到明账上"。引到——是暗手看明账——他想着这个，又想着看的账——暗手看明账，是上钩——他想着这个，把这个念头放好：上钩的账，他等。

他又想了一遍"上钩的账，他等"。上钩——是暗手看明账——他想着这个，又想着钩的账——钩住了，是露了——他想着这个，把这个念头放好：露的账，他等。

他又想了一遍"实账不怕照"。不怕照——是照得亮——他想着这个，又想着亮的账——亮，是没藏——他想着这个，把这个念头放好：亮的账，他核。

他又想了一遍"没藏"。没藏——是账干净——他想着这个，又想着净的账——干净，照得亮——他想着这个，把这个念头放好：净的账，他摆。

他又想了一遍"净的账，他摆"。净——是账干净——他想着这个，又想着净的账——干净，照得亮——他想着这个，把这个念头放好：亮的账，他摆。

他整理了一卷，又整理一卷。整理的，都是他核实的账——他想着这个，又想着整的账——整好，摆明——他想着这个，把这个念头放好：整好的账，他摆。

他又想了一遍"整的样子"。整——是一卷一卷理——他想着这个，又想着理的账——理清，摆明——他想着这个，把这个念头放好：理清的账，他摆。

他又想了一遍"理清的账，他摆"。理清——是账理清了——他想着这个，又想着理的账——理清，摆得明——他想着这个，把这个念头放好：摆明的账，他做。

他推演。

第一步，立结论：明账整理完了——他核实的账，都摆好了——摆明面，等暗手。

第二步，摆依据，三样。一，整——他核实的账，一卷一卷整理好；二，摆——整理好的，摆到明处——档房能查；三，等——明账摆出去，暗手会来——来了，就露。三样并排：整好，摆明，等来——明账，他摆出去了。

第三步，定行动。明账摆出去了——他盯着——看暗手什么时候来。

他数了三息，把三步在心里过完。

他又想了一遍"看暗手什么时候来"。看——是等着——他想着这个，又想着等的账——等着，是钓——他想着这个，把这个念头放好：钓的账，他守。

他又想了一遍"钓"。钓——是拿明账钓——他想着这个，又想着钓的账——饵是实账，钩是明账——他想着这个，把这个念头放好：饵钩的账，他做。

他又想了一遍"饵钩的账，他做"。饵钩——是明账做饵——他想着这个，又想着做的账——饵下了，钩等着——他想着这个，把这个念头放好：等钩的账，他记。

他又想了一遍他摆的明账。明账——摆的是实的——他想着这个，又想着实的账——实的，不怕看——他想着这个，把这个念头放好：实的账，他守。

他又想了一遍"不怕看"。不怕看——是摆得明——他想着这个，又想着明的账——明，是照得亮——他想着这个，把这个念头放好：照亮的账，他做。

他又想了一遍"照亮的账，他做"。照亮——是账照得亮——他想着这个，又想着亮的账——照亮，是没藏——他想着这个，把这个念头放好：没藏的账，他做。

他合上案上的账，出了档房。

他又想了一遍今日的账。今日——明账整理完——摆出去了——他想着这个，把这个念头放好：今日的账，记下——记下的账，他盯着。

他又想了一遍明账的分量。明账——是黑名单反击的第一手——他想着这个，又想着手的账——第一手，是明账——他想着这个，把这个念头放好：第一手的账，他记。

他又想了一遍"第一手"。第一手——是反击的头一手——他想着这个，又想着头的账——头开好了，后手接着——他想着这个，把这个念头放好：后手的账，他备。

他又想了一遍"后手的账，他备"。后手——是反击的后手——他想着这个，又想着后的账——后手备好，前手不空——他想着这个，把这个念头放好：备的账，他记。

他又想了一遍后手。后手——是把暗手引到明账——他想着这个，又想着后的账——后手到，暗手现——他想着这个，把这个念头放好：现手的日子，他等。

他又想了一遍"现手的日子，他等"。现手——是暗手现形——他想着这个，又想着现的账——现了，是能抓——他想着这个，把这个念头放好：能抓的账，他等。

他吹熄灯，躺下。黑暗里，他想着明账，想着暗手，想着第一手的账——他想着这个，把这个念头放好：明账的账，他记着——记着的账，他核着。

他又想了一遍"他核着"。他核着——明账摆出去了——他想着这个，又想着核的账——核着，是盯着——他想着这个，把这个念头放好：盯着的账，他守。

他又想了一遍"盯着的账，他守"。盯着——是看明账的动静——他想着这个，又想着动的账——动静来了，是暗手——他想着这个，把这个念头放好：动来的账，他接。

他又想了一遍接的样子。接——是接暗手的来——他想着这个，又想着接的账——接住了，是坐实——他想着这个，把这个念头放好：坐实的账，他记。

他翻了个身，把这个打算放好，沉沉睡去。
