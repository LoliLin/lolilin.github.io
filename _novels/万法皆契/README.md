# 01 需求文档：长篇原创智斗网文创作需求

> 状态：阶段 1 交付物 · 日期：2026-08-06
> 本文档把用户口味转译为**可验收**的创作需求条目。能量化的给出量化标准，不能量化的给出"检查清单"式判定。

## 0. 读者定位与项目目标

- 读者：成年读者，偏好烧脑网文（接受复杂推演、灰色主角、非圆满结局）。
- 目标：一部 100–300 万字的原创长篇，靠"智斗密度 + 规则世界观 + 套娃格局"取胜，而非爽文套路。
- 体量规划：100–300 万字 ≈ 8–12 卷，每卷 10–30 万字。

## 1. 用户口味原文（必须忠实保留）

1. 智斗密度极高：信息差、人心操控、布局反布局、时间线推演；读者要跟着动脑，并发现"早几章就埋好的线"。
2. 主角"真"：目标明确到变态、手段冷酷、彻底的利己主义+超强执行力；不自我感动、无道德洁癖；让读者又恨又爽。
3. 胜利有真实代价：寿命、人情、底牌暴露、仇家加深；短期胜利埋长期雷；"赢"本身是为了下一盘更大的局。
4. 世界观扎实可推导：规则成体系（可组合、可克制、有副作用），细节能回收，越读越发现前文埋雷。
5. 节奏：压抑—爆发—再压抑的循环，情绪反差拉满。
6. 哲学张力：通过情节而非说教，追问自由、道德、命运。
7. 世界观俄罗斯套娃：小格局→中格局→大格局，不断推翻读者认知，上层还有更高棋手。

## 2. 硬性约束（违反即不通过）

- C1 原创性：不得使用《蛊真人》的蛊虫体系、五域、天庭、宿命蛊、方源等具体设定与人物；仅保留其"叙事 DNA"。验收：概念设计附原创性对照表逐项确认。
- C2 语言与读者：中文写作，面向喜欢烧脑网文的成年读者。
- C3 阶段边界：本阶段只交付需求文档与概念设计，不写正文。

## 3. 需求条目

每条需求给出：描述 → 可验收标准 → 验收方式。

### R1 智斗密度（口味 1）

- 描述：信息差、人心操控、布局反布局、时间线推演是叙事主干，不是点缀。
- 可验收标准：
  - R1.1 每 3–5 章至少 1 次"信息差反转"（读者或某方角色掌握的信息被证明不完整/被颠覆）。
  - R1.2 每卷至少 3 条"跨章伏笔链"：铺设点与回收点相隔 ≥ 10 章，且回收时读者回看铺设点"有迹可循"。
  - R1.3 主角不是全知：每卷至少 1 次主角被反将/判断失误，且该失误可由前文信息推出。
  - R1.4 时间线推演：全书至少 3 个以"时间戳/时序矛盾"为关键证据的反转。
- 验收方式：按卷建立"伏笔台账"（铺设章节→回收章节→可回看性打分）；样章阶段 20 人盲测"是否回看前文"。

### R2 主角人设（口味 2）

- 描述：主角目标明确到变态、手段冷酷、彻底利己、执行力超强、不自我感动、无道德洁癖。
- 可验收标准：
  - R2.1 开篇 3 万字内明确长线目标，且目标可拆成可执行的阶段性计划。
  - R2.2 每卷至少 1 次"利己优先于情义"的关键抉择：牺牲盟友 / 利用感情 / 放弃拯救，事后主角不忏悔、不抒情。
  - R2.3 主角内心独白只用于推演与布局，禁止自我感动式抒情（全书抒情式独白 ≤ 3 处，且须服务于人设反差）。
  - R2.4 主角的"坏"是计算的结果而非标签：每次冷酷行为都能在规则系统内自洽（成本意识）。
- 验收方式：每卷评审逐条核对；读者问卷确认"恨主角的点"与"爽的点"同时成立。

### R3 胜利的代价（口味 3）

- 描述：任何胜利都伴随可感知代价；短期胜利埋长期雷；赢是为了下一盘更大的局。
- 可验收标准：
  - R3.1 每次重大胜利必须伴随 ≥ 1 项可感知代价。代价池至少包含：寿命/健康、人情透支、底牌暴露、仇家升级、资源消耗、信誉受损。
  - R3.2 每次重大胜利必须埋 ≥ 1 个后续雷（本卷不引爆，后续 ≥ 10 章内回收或升级）。
  - R3.3 全书禁止"无代价胜利"；表面"白赚"的胜利必须在 ≤ 3 章内揭示真实代价。
  - R3.4 胜利必须服务于更大目标：每次胜利之后，主角的下一个目标比上一个更大（局中局）。
- 验收方式：建立"胜利-代价-埋雷"台账，每卷末逐条对账。

### R4 规则体系（口味 4）

- 描述：世界观规则成体系，可组合、可克制、有副作用，细节能回收。
- 可验收标准：
  - R4.1 选定方案须有"规则白皮书"：规则条目化，每条含【定义】【组合】【克制】【副作用】四栏。
  - R4.2 主角所有胜利手段必须在前文可查：禁止临时发明规则/底牌（"后设能力"禁止）。
  - R4.3 每条规则至少被使用 2 次（第 1 次建立认知，第 2 次展现组合/克制/副作用）。
  - R4.4 细节回收：设定中的闲笔（人名、物件、数字）≥ 60% 在 30 万字内回收。
- 验收方式：规则白皮书随卷更新；按 R4.2 抽查关键反转章节。

### R5 节奏（口味 5）

- 描述：压抑—爆发—再压抑循环，情绪反差拉满。
- 可验收标准：
  - R5.1 每卷 ≥ 1 次完整"压抑→爆发"循环；爆发前压抑铺垫 ≥ 3 章（连续低气压/压制/挫败）。
  - R5.2 每次爆发须由"信息差/布局"引爆，而非单纯武力升级。
  - R5.3 每卷结尾处于"再压抑"状态（新雷埋下、代价浮现、局面更险）；全书禁止连续两卷以胜利收尾。
- 验收方式：每章情绪值打点成曲线图，每卷评审对照。

### R6 哲学张力（口味 6）

- 描述：通过情节而非说教，追问自由、道德、命运。
- 可验收标准：
  - R6.1 全书 ≥ 3 个"两难困境"情节：无论怎么选都有真实代价，主角的选择让读者不适但逻辑自洽。
  - R6.2 直接议论（主角/旁白输出道理）每卷 ≤ 1 次，且必须由情节事件触发、篇幅 ≤ 500 字。
  - R6.3 哲学问题必须由具体情节"演示"，禁止抽象说理替代情节。
- 验收方式：编辑标注每处议论并检查是否超标；两难困境计入台账。

### R7 套娃世界观（口味 7）

- 描述：小格局→中格局→大格局，不断推翻读者认知，上层还有更高棋手。
- 可验收标准：
  - R7.1 格局层级 ≥ 3 层，每层有独立的规则/舞台/对手类型。
  - R7.2 每次格局升级必须"推翻读者既有认知"（信息差升级），且升级线索在前文有伏笔。
  - R7.3 上层棋手必须是"人/组织/规则"而非抽象背景：可对话、可博弈、有动机。
- 验收方式：格局层级图 + 升级伏笔表。

### R8 原创性自查（约束 C1 落地）

- 可验收标准：概念设计附对照表，对《蛊真人》具体设定（蛊虫体系/五域/天庭/宿命蛊/方源）逐项确认"未采用"；对叙事 DNA（智斗/代价/信息差/套娃）逐项确认"已承载"。
- 验收方式：定稿前人工审查；老读者抽查是否联想到具体抄袭。

### R9 体量与卷规划

- 可验收标准：概念定稿时给出 8–12 卷的卷纲骨架；每卷有独立"卷命题"与"卷间钩子"。
- 验收方式：卷纲评审。

### R10 烧脑而不劝退

- 描述：信息差要"可回看"而非"不可知"。
- 可验收标准：
  - R10.1 每个反转回收时，读者凭前文信息可自行推理出（盲测通过率 ≥ 50%）。
  - R10.2 关键规则首次出现时给出"读者能懂"的最小示例。
  - R10.3 每卷最多 1 个"必须靠番外/设定集才能看懂"的伏笔。
- 验收方式：样章阶段盲测。

## 4. 需求优先级

- P0（必须）：R1、R2、R3、R4、R7（口味 1–4、7 是本项目立身之本）。
- P1（强烈建议）：R5、R6（节奏与哲学张力）。
- P2（工程保障）：R8、R9、R10。
